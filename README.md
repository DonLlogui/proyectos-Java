## 📖 Descripción

**FacturaSimple** es una simulación en consola que permite generar facturas a partir de clientes y artículos. El proyecto pone en práctica los principios fundamentales de la **Programación Orientada a Objetos (POO)**, tales como encapsulamiento, composición y abstracción.

## ✨ Características

- 🧑‍💼 Clase `Cliente` con datos personales (nombre, RUT/dni, dirección).
- 📦 Clase `Artículo` con atributos como nombre, precio y cantidad.
- 🧾 Clase `Factura` que integra cliente y artículos para calcular totales.
- 💰 Cálculo automático de subtotal, IVA e importe total.
- 🖨️ Impresión formateada de la factura en ventana JOptionPane.
